# chimera

A 2D game engine written in C++ using SDL3.

---

## About

I'm building chimera as a passion project. The engine's fundamentals are inspired by Godot's nodes. 

**This is not meant to be used by other people.** This engine was built only for my intentions and purposes built with my current knowledge and skills of C++. I'm still a beginner so expect to come across a lot of strange conventions or habit. However, please feel free to give feedback as that would help me immensely!
